# Security policy

AutumnApply handles highly sensitive personal information. Treat privacy failures as security issues.

## Never commit

- names, phone numbers, email addresses or identity numbers from real candidates;
- resumes, transcripts, certificates or profile photos;
- browser cookies, saved sessions or storage state;
- API keys, passwords or verification codes;
- private recruiter messages or application answers.

Use synthetic fixtures in tests. Local candidate data belongs under ignored paths such as `data/` or `private/`.

## Reporting

Until a private reporting channel is established, avoid posting exploitable details or personal data in a public issue. Open a minimal issue asking the maintainer for a private contact method.
